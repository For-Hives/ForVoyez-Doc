# WordPress Plugin: Auto Alt Text for Images

## Introduction

Auto Alt Text for Images is the ForVoyez plugin for WordPress. It sends the images of your media library to the ForVoyez API and saves the generated alternative text (alt text), title, and caption on each image, to improve your website's accessibility and search engine optimization.

The plugin is free and published on WordPress.org: [wordpress.org/plugins/auto-alt-text-for-images](https://wordpress.org/plugins/auto-alt-text-for-images/). Each analysed image uses 1 credit from your ForVoyez account.

<ScreenSchema />

## Key Features

- AI-generated alt text, title, and caption for each image
- Analysis of a single image from the media library
- Bulk analysis of existing images, from the plugin's Manage Images tab or from the Media Library bulk actions
- Optional automatic analysis of new uploads
- Output in the language of your choice, with an optional context sent with every image
- Your remaining ForVoyez credits shown in the plugin

## Requirements

- WordPress 5.6 or later and PHP 8.0 or later
- A ForVoyez account with credits, and an API key (see [Configuration](#configuration))
- Images in JPEG, PNG, WebP, or GIF format, up to 10 MB each: the API refuses other formats, such as AVIF or HEIC, and larger files

## Installation

1. In your WordPress admin area, go to **Plugins > Add New Plugin**.
2. Search for **Auto Alt Text for Images**.
3. Click **Install Now** on the plugin by ForVoyez, then **Activate**.

The plugin adds an **Auto Alt Text** menu to your WordPress admin area, with three tabs: **Dashboard**, **Manage Images**, and **Configuration**.

You can also download the zip file from the [plugin page on WordPress.org](https://wordpress.org/plugins/auto-alt-text-for-images/) and install it from **Plugins > Add New Plugin > Upload Plugin**. The source code is on [GitHub](https://github.com/For-Hives/ForVoyez-Wordpress-plugin).

## Configuration

### Getting an API Key

If you don't have an API key yet:

1. Visit the [ForVoyez signup page](https://forvoyez.com/sign-up) to create an account, and choose a plan or a credit pack on the [Plans](https://forvoyez.com/app/plans) page.
2. Open the [API Keys](https://forvoyez.com/app/tokens) page of your dashboard and click **Add token**.
3. Give the key a name (for example the name of your website) and an expiration date, then click **Create Token**.
4. Copy the key: it is displayed only once.

### Saving the API Key in WordPress

1. Go to **Auto Alt Text > Configuration**.
2. Paste the key in the **API Key** field of the **API Configuration** section.
3. Click **Save API Key**. The plugin refuses a value that does not have the format of a ForVoyez API key, such as a password filled in by your browser.

<ScreenConfiguration />

The **Dashboard** tab then shows your **Remaining Credits**. If the key is wrong, deleted, or expired, it shows the error returned by the API instead, for example `Unauthorized, invalid token`: create a new key and save it again.

### Additional Settings

The **Additional Configuration (optional)** section of the **Configuration** tab has three settings:

- **Context**: a text sent with every image to guide the generation, for example the topic of your website.
- **Language**: the language of the generated texts, as a language code (`en`, `fr`, `pt-BR`...) or a language name. When it is empty, the texts are in English.
- **Enable automatic image analysis on upload**: when this switch is on, every new image you upload is analysed automatically. It is off by default, and it is saved as soon as you change it.

Click **Save Additional Settings** to save the context and the language.

## Usage

### Dashboard

The **Dashboard** tab gives you an overview of your media library:

<ScreenDashboard />

- **Total Images**: the number of items in your media library.
- **Images Completed**: the number of images that have an alt text.
- **Images Without alt / caption**: the number of images that miss an alt text, a title, or a caption.
- **Automatic Image Analysis**: whether automatic analysis of new uploads is enabled.
- **ForVoyez Credits**: your remaining ForVoyez credits.

### Manage Images

The **Manage Images** tab shows your images in a grid, with a legend for the missing metadata (Missing Alt Text, Missing title, Missing caption, All complete).

<ScreenManage />

To analyse images from this tab:

- Click **Analyse** under an image to analyse only that image, or **Details** to see its current alt text, title, and caption.
- Select images with their checkboxes (or **Select All**), then click **Analyze Selected Images**.
- Or click one of the buttons at the top: **Analyze all missing alt/caption/title images**, **Analyze all missing alt images**, or **Analyze all images**. Each button shows the number of images it will analyse.

Before a bulk analysis starts, a confirmation shows its cost in credits (1 credit per image) and your remaining credits.

### Media Library

You can also analyse images from **Media > Library**:

- In the list view, select images, choose **Analyze with ForVoyez** in the **Bulk actions** menu, and click **Apply**. A notice shows the number of images and your credits: click **Start Analysis** to run it.
- In the details of an image, click the **Analyze with ForVoyez** button.

### Automatic Analysis

When **Enable automatic image analysis on upload** is on, the plugin analyses each new image shortly after the upload, in the background (with WP-Cron). No image is sent to ForVoyez while no API key is saved.

### Results

For each analysed image, the plugin saves the generated alt text in the image's **Alternative Text** field, the title in its **Title**, and the caption in its **Caption**. An empty value never replaces existing text, and you can edit any generated text by hand in the media library.

When an analysis fails, the plugin shows the error message returned by the API, and the image keeps its current texts. The most common ones are `Unauthorized, no credit left` (buy credits on the [Plans](https://forvoyez.com/app/plans) page), `Bad Request, Invalid image file` (the image is not a JPEG, PNG, WebP, or GIF file), and `Image too large: the maximum is 10 MB`. See [Error Codes](/error-codes) for the others. A failed analysis does not use a credit.
