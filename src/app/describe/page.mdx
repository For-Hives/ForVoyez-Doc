# /describe Endpoint

The `/describe` endpoint allows you to generate metadata for your images using the ForVoyez API. By sending a POST request to this endpoint with an image file and optional parameters, you can obtain a title, alternative text, and caption for the image in your desired language.

## Request

### Endpoint

```
POST https://forvoyez.com/api/describe
```

### Headers

- `Authorization` (required): The authentication token (API key) to authorize the request. The token should be prefixed with `Bearer `.
- `Content-Type` (required): The content type of the request body. It should be set to `multipart/form-data`.

### Request Body

The request body should be in `multipart/form-data` format and include the following fields:

- `image` (required): The image file for which you want to generate metadata. Supported image formats are JPEG, JPG, PNG, WebP, and GIF, up to 10 MB.
- `schema` (optional): A JSON string with a flat object that maps each output field to a short description of what to generate, with at most 20 fields. See [Schemas](#schemas) below.
- `keywords` (optional): A comma-separated list of keywords to assist in generating more accurate metadata. Only the first 1,000 characters are used.
- `context` (optional): Additional context or description to assist in generating more accurate metadata. Only the first 1,000 characters are used.
- `language` (optional): A string specifying the desired language for the metadata output, up to 64 characters. If not provided, the default is English ('en').

### Example Request

```bash
curl -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: multipart/form-data" \
  -F "image=@/path/to/your/image.jpg" \
  -F "schema={\"title\":\"A short title for the image\",\"alternativeText\":\"Alt text for screen readers\",\"caption\":\"A one-sentence caption\"}" \
  -F "keywords=playful,kittens" \
  -F "context=Playful kittens" \
  -F "language=fr" \
  https://forvoyez.com/api/describe
```

## Response

### Success Response

If the request is successful, the API will return a `200 OK` status and a flat JSON object containing the generated metadata for the provided image in the specified language. The object has exactly the keys of your schema (or `title`, `alternativeText`, and `caption` when no schema is sent), and every value is a string. When the request has no `schema` field, the object also has `alt_text`, a copy of `alternativeText` kept for older versions of the WordPress plugin.

```json
{
	"title": "Chatons joueurs",
	"alternativeText": "Deux chatons jouant avec une pelote de laine",
	"caption": "Adorables chatons s'amusant et faisant des bêtises"
}
```

### Error Responses

If the request is unsuccessful, the API will return an appropriate HTTP status code along with a JSON body (`Content-Type: application/json`) whose `error` field contains a human-readable message:

```json
{
	"error": "Unauthorized, no credit left"
}
```

Here are the possible error responses:

- `400 Bad Request`
  - `Bad Request, No file uploaded`: The `image` field is missing in the request.
  - `Bad Request, Invalid image file`: The uploaded file is not a JPEG, PNG, WebP, or GIF image.
  - `Invalid schema: ...`: The `schema` is over the [schema limits](/data-schemas#schema-validation): more than 20 fields, a field name longer than 64 characters, a description longer than 1,000 characters, or a field named `__proto__`. The rest of the message names the limit, for example `Invalid schema: at most 20 fields are allowed`.

- `401 Unauthorized`
  - `Unauthorized, missing Authorization header`: The `Authorization` header is missing in the request.
  - `Unauthorized, invalid token`: The provided API key is invalid, has expired, or has been deleted from the dashboard.
  - `Unauthorized, no credit left`: The user has insufficient credits to make the request.

- `500 Internal Server Error`: An unexpected error occurred on the server side, or the image could not be processed. An image larger than 10 MB also returns this status: the `error` message is then usually `Image processing failed: Image size exceeds the maximum limit of 10 MB`, but it can be `Internal Server Error` for much larger uploads.

For more details on error codes and messages, refer to the [Error Codes](/error-codes) documentation.

## Authentication

To use the `/describe` endpoint, you need to include a valid API key in the `Authorization` header of your request. The API key should be prefixed with `Bearer `.

If you don't have an API key yet, sign up for a ForVoyez account and obtain your API key from the [Dashboard](https://forvoyez.com/app).

## Credits

Each successful request to the `/describe` endpoint uses 1 credit from your balance. A request that fails does not use any credit. When your balance is empty, the API returns `401 Unauthorized` with the message `Unauthorized, no credit left`.

See [Limits and Quotas](/limits-and-quotas) to learn how credits are added to your balance.

## Schemas

You can customize the output fields of the generated metadata by providing a schema in the `schema` field of the request. The schema is a flat JSON object: each key is an output field and each value describes what to generate for it. Nested objects and arrays are not supported, and every value in the response is a string.

Here's an example schema:

```json
{
	"title": "A short title for the image",
	"alternativeText": "Alt text for screen readers",
	"caption": "A one-sentence caption",
	"tags": "Five comma-separated keywords describing the image"
}
```

If no schema is provided, the API will use a default schema that returns `title`, `alternativeText`, and `caption`. A schema can have at most 20 fields, with field names up to 64 characters and descriptions up to 1,000 characters; a larger schema is rejected with `400 Bad Request`. See [Data Schemas](/data-schemas) for more details.

```bash {{title: 'cURL'}}
curl -X POST \
-H "Authorization: Bearer YOUR_API_KEY" \
-H "Content-Type: multipart/form-data" \
-F "image=@/path/to/your/image.jpg" \
-F "schema={\"title\":\"A short title for the image\",\"alternativeText\":\"Alt text for screen readers\",\"caption\":\"A one-sentence caption\"}" \
```

```python {{ title: 'Python' }}
import requests

url = "https://forvoyez.com/api/describe"
api_key = "YOUR_API_KEY"

files = [
    ('image', ('image.jpg', open('/path/to/your/image.jpg', 'rb'), 'image/jpeg'))
]

payload = {
    'schema': '{"title":"A short title for the image","alternativeText":"Alt text for screen readers","caption":"A one-sentence caption"}',
    'keywords': 'playful,kittens',
    'context': 'Playful kittens',
    'language': 'fr'
}

headers = {
    'Authorization': f'Bearer {api_key}'
}

response = requests.post(url, headers=headers, data=payload, files=files)

print(response.json())
```
