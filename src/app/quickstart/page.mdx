# Quick Start

Welcome to the quick start guide for the ForVoyez API. In this section, we'll walk you through the process of signing up for an account, obtaining your API key, and making your first API call to generate metadata for an image.

## Signing Up and Creating an Account

To get started with the ForVoyez API, you'll need to create an account. Follow these steps:

1. Visit the [ForVoyez website](https://forvoyez.com) and click on the "Sign Up" button.
2. Fill out the registration form with your email address and a strong password.
3. Verify your email address by clicking on the confirmation link sent to your inbox.
4. Once your email is verified, log in to your account.

You can also sign up using your Google or GitHub account for a quicker registration process.

## Obtaining the API Key

After logging in to your account, you'll need to obtain your API key. Here's how:

1. Navigate to the [API Keys](https://forvoyez.com/app/tokens) page in your account dashboard.
2. Click on the "Add token" button, give the key a name and an expiration date, then click "Create Token".
3. Copy your API key and store it in a secure location, such as an environment variable on your server. You'll need this key to authenticate your requests to the ForVoyez API.
4. Be careful, the key is only displayed once, so make sure to save it before you click "I copied it".

## Making Your First API Call

Now that you have your API key, you're ready to make your first API call to generate metadata for an image. Below are examples using cURL and JavaScript. Run them on your server, never in a web page: an API key in browser code can be read and used by anyone. The JavaScript example is for Node.js 20 or later (save it as a `.mjs` file) and reads your API key from the `FORVOYEZ_API_KEY` environment variable.

<CodeGroup>
```bash {{ title: 'cURL' }}
curl -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "image=@/path/to/your/image.jpg" \
  -F "schema={\"title\":\"A short title for the image\",\"alternativeText\":\"Alt text for screen readers\",\"caption\":\"A one-sentence caption\"}" \
  -F "keywords=image,description" \
  -F "context=Your image context" \
  -F "language=en" \
  https://forvoyez.com/api/describe
```

```js {{ title: 'JavaScript' }}
// Server-side only (Node.js 20 or later): never put your API key in browser
// code. The key is read from the FORVOYEZ_API_KEY environment variable.
import { readFile } from 'node:fs/promises'

const image = new Blob([await readFile('/path/to/your/image.jpg')])

const form = new FormData()
form.append('image', image, 'image.jpg')
form.append(
	'schema',
	JSON.stringify({
		title: 'A short title for the image',
		alternativeText: 'Alt text for screen readers',
		caption: 'A one-sentence caption',
	})
)
form.append('keywords', 'image,description')
form.append('context', 'Your image context')
form.append('language', 'en')

const response = await fetch('https://forvoyez.com/api/describe', {
	method: 'POST',
	headers: {
		Authorization: `Bearer ${process.env.FORVOYEZ_API_KEY}`,
	},
	body: form,
})
const data = await response.json()

if (!response.ok) {
	// Error bodies are {"error": "<message>"}: see the Error Codes page
	throw new Error(`ForVoyez API error ${response.status}: ${data.error}`)
}

console.log(data)
```

</CodeGroup>

Make sure to replace `YOUR_API_KEY` with your actual API key (or set the `FORVOYEZ_API_KEY` environment variable for the JavaScript example) and `/path/to/your/image.jpg` with the path to the image file you want to generate metadata for. Each successful request uses 1 credit.

The request includes the following parameters:

- `image` (required): The image file you want to generate metadata for.
- `schema` (optional): A JSON string with a flat object that maps each output field to a short description of what to generate.
- `keywords` (optional): A comma-separated list of keywords to help guide the metadata generation.
- `context` (optional): Additional context about the image to improve accuracy.
- `language` (optional): The desired language for the metadata output (defaults to 'en' for English).

The API will process your request and return a JSON response containing the generated metadata based on your specified schema and language.
