# Code Examples

To help you get started with integrating the ForVoyez API into your application, we provide code examples in various programming languages. These examples demonstrate how to make a request to the `/describe` endpoint to generate metadata for an image, and to the `/tokens` endpoint to check an API key.

Run these examples on your server, never in a web page: an API key sent to a browser can be read and used by anyone. To analyse images that your visitors upload, send them to your server first and call the ForVoyez API from there. The JavaScript examples are for Node.js 20 or later (save them as `.mjs` files) and read your API key from the `FORVOYEZ_API_KEY` environment variable.

## Generating Metadata for an Image

<CodeGroup>
```bash {{ title: 'cURL' }}
curl -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "image=@/path/to/your/image.jpg" \
  -F "schema={\"title\":\"A short title for the image\",\"alternativeText\":\"Alt text for screen readers\",\"caption\":\"A one-sentence caption\"}" \
  -F "keywords=playful,kittens" \
  -F "context=Playful kittens" \
  -F "language=en" \
  https://forvoyez.com/api/describe
```

```python {{ title: 'Python' }}
import requests

url = "https://forvoyez.com/api/describe"
api_key = "YOUR_API_KEY"

files = [
    ('image', ('image.jpg', open('/path/to/your/image.jpg', 'rb'), 'image/jpeg'))
]

payload = {
    'schema': '{"title":"A short title for the image","alternativeText":"Alt text for screen readers","caption":"A one-sentence caption"}',
    'keywords': 'playful,kittens',
    'context': 'Playful kittens',
    'language': 'en'
}

headers = {
    'Authorization': f'Bearer {api_key}'
}

response = requests.post(url, headers=headers, data=payload, files=files)

print(response.json())
```

```javascript {{ title: 'JavaScript' }}
// Server-side only (Node.js 20 or later): never put your API key in browser
// code. The key is read from the FORVOYEZ_API_KEY environment variable.
import { readFile } from 'node:fs/promises'

const image = new Blob([await readFile('/path/to/your/image.jpg')])

const form = new FormData()
form.append('image', image, 'image.jpg')
form.append(
	'schema',
	JSON.stringify({
		title: 'A short title for the image',
		alternativeText: 'Alt text for screen readers',
		caption: 'A one-sentence caption',
	})
)
form.append('keywords', 'playful,kittens')
form.append('context', 'Playful kittens')
form.append('language', 'en')

const response = await fetch('https://forvoyez.com/api/describe', {
	method: 'POST',
	headers: {
		Authorization: `Bearer ${process.env.FORVOYEZ_API_KEY}`,
	},
	body: form,
})
const data = await response.json()

if (!response.ok) {
	// Error bodies are {"error": "<message>"}: see the Error Codes page
	throw new Error(`ForVoyez API error ${response.status}: ${data.error}`)
}

console.log(data)
```

```php {{ title: 'PHP' }}
<?php

$url = 'https://forvoyez.com/api/describe';
$api_key = 'YOUR_API_KEY';

$data = [
    'schema' => json_encode([
        'title' => 'A short title for the image',
        'alternativeText' => 'Alt text for screen readers',
        'caption' => 'A one-sentence caption'
    ]),
    'keywords' => 'playful,kittens',
    'context' => 'Playful kittens',
    'language' => 'en'
];

$image_path = '/path/to/your/image.jpg';
$image_mime = mime_content_type($image_path);
$image_name = basename($image_path);
$image_data = file_get_contents($image_path);

$boundary = uniqid();
$delimiter = '-------------' . $boundary;

$post_data = build_data_files($boundary, $data, $image_name, $image_mime, $image_data);

$headers = [
    'Authorization: Bearer ' . $api_key,
    'Content-Type: multipart/form-data; boundary=' . $delimiter,
    'Content-Length: ' . strlen($post_data)
];

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, $post_data);
curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);

$result = curl_exec($ch);

echo $result;

function build_data_files($boundary, $fields, $file_name, $file_mime, $file_data) {
    $data = '';
    $delimiter = '-------------' . $boundary;

    foreach ($fields as $name => $content) {
        $data .= "--" . $delimiter . "\r\n"
            . 'Content-Disposition: form-data; name="' . $name . "\"\r\n\r\n"
            . $content . "\r\n";
    }

    $data .= "--" . $delimiter . "\r\n"
        . 'Content-Disposition: form-data; name="image"; filename="' . $file_name . '"' . "\r\n"
        . 'Content-Type: ' . $file_mime . "\r\n\r\n"
        . $file_data . "\r\n";

    $data .= "--" . $delimiter . "--\r\n";

    return $data;
}
```

</CodeGroup>

These code examples demonstrate how to make a POST request to the `/describe` endpoint using different programming languages. Make sure to replace `YOUR_API_KEY` with your actual API key (or set the `FORVOYEZ_API_KEY` environment variable for the JavaScript example) and provide the path to your image file.

The request includes the following parameters:

- `image`: The image file (required)
- `schema`: JSON string with a flat object mapping each output field to a description (optional)
- `keywords`: Comma-separated list of keywords (optional)
- `context`: Additional context about the image (optional)
- `language`: Desired language for the output (optional, defaults to 'en')

For more detailed information on the request parameters and response format, refer to the [/describe](/describe) endpoint documentation.

## Checking an API Key and Your Credits

A `GET` request to the `/tokens` endpoint checks an API key and returns the credit balance of its account. It uses no credit.

<CodeGroup>
```bash {{ title: 'cURL' }}
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://forvoyez.com/api/tokens
```

```python {{ title: 'Python' }}
import requests

url = "https://forvoyez.com/api/tokens"
api_key = "YOUR_API_KEY"

response = requests.get(url, headers={'Authorization': f'Bearer {api_key}'})
data = response.json()

if response.ok:
    print(data['user']['credits'], 'credits left')
else:
    print('Error', response.status_code, data['error'])
```

```javascript {{ title: 'JavaScript' }}
// Server-side only (Node.js 20 or later): never put your API key in browser
// code. The key is read from the FORVOYEZ_API_KEY environment variable.
const response = await fetch('https://forvoyez.com/api/tokens', {
	headers: {
		Authorization: `Bearer ${process.env.FORVOYEZ_API_KEY}`,
	},
})
const data = await response.json()

if (!response.ok) {
	// Error bodies are {"error": "<message>"}: see the Error Codes page
	throw new Error(`ForVoyez API error ${response.status}: ${data.error}`)
}

console.log(`${data.user.credits} credits left`)
```

```php {{ title: 'PHP' }}
<?php

$url = 'https://forvoyez.com/api/tokens';
$api_key = 'YOUR_API_KEY';

$ch = curl_init($url);
curl_setopt($ch, CURLOPT_HTTPHEADER, ['Authorization: Bearer ' . $api_key]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);

$data = json_decode(curl_exec($ch), true);
$status = curl_getinfo($ch, CURLINFO_RESPONSE_CODE);

if ($status === 200) {
    echo $data['user']['credits'] . ' credits left';
} else {
    echo 'Error ' . $status . ': ' . $data['error'];
}
```

</CodeGroup>

See the [/tokens](/tokens) endpoint documentation for all the fields of the response and its error messages.
